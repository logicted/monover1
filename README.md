# monover1

An early static-site experiment using HTML, CSS, and the Cayman theme.

## Status

Historical experiment. The repository contains a minimal page and theme styles; it is not a finished portfolio or production application.

## Contents

- `index.html`: the page markup.
- `stylesheets/`: theme, normalization, and syntax styles.
- `params.json`: metadata used by the original page generator.

The existing default branch is `gh-pages`.

## Preview locally

Download the repository and open `index.html` in a browser. No package installation or build step is required. The Google Fonts resource requires an internet connection; system fonts provide a fallback.

## Attribution

The page was generated with [GitHub Pages](https://pages.github.com/) and uses the [Cayman theme by Jason Long](https://github.com/jasonlong/cayman-theme). Preserve the theme credits when editing the page.

## Limitations

Download buttons use the `gh-pages` branch. A deployment URL has not been verified.
